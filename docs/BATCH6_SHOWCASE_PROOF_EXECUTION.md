# Batch 6 Showcase execution reference

The current end-to-end procedure is the root
[Publication Operating Guide](../PUBLICATION_GUIDE.md). Use that guide and
`npm run publication`; the older v1 unsigned files and three-confirmation
procedure are superseded by sealed v2 plans and Base finalized-block checks.

The reviewed cohort remains 60 original forecasts: all 12 for each of PepsiCo,
NVIDIA, Bitcoin, Alphabet and SPY. Each asset is one `multiAttest` transaction;
each forecast retains its own receipt and EAS UID. The schema needs a separate
one-time registration when absent. Selection is independent of outcomes.

The unsigned Sep 10 preparation evidence is retained in the operations backup
area. It is not proof of issuance. Do not use the old six-receipt
`eas-showcase.mjs` demonstration command for the complete live cohort.
